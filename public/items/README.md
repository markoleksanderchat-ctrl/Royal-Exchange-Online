# Vanilla commodity sprites

All 1,332 PNGs were rendered with Minecraft 1.21.1's actual default item renderer in an isolated title-screen fixture. No world, saved game, multiplayer connection or installed mod was used for rendering. Each image is 32 × 32 RGBA; transparency was recovered from paired white/black framebuffers so the same assets work in both site themes.

The item models and textures are Minecraft assets owned by Mojang/Microsoft. The catalogue and issuer mappings are unchanged.
